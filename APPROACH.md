# Project Approach

## 1. Understanding the Problem
The goal is to analyze students' marks and display useful information such as average, highest and lowest marks.

## 2. Logic Used
- Take the number of students as input.
- Accept each student's name and marks.
- Store the names and marks.
- Calculate the total marks.
- Calculate the average.
- Find the highest and lowest marks.
- Display all students who obtained the highest marks.

## 3. Input Validation
The program checks that marks are within the range of 0 to 100.

## 4. Edge Cases
The program considers:
- Marks equal to 0.
- Marks equal to 100.
- Multiple students having the same highest marks.

## 5. Conclusion
This project demonstrates the use of Java input, arrays, loops, conditions and basic calculations.
