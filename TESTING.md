# Testing Documentation

The following test cases are used to check the Student Marks Analyzer.

## Test Case 1: Normal Input
Enter valid student names and marks.
Expected: The program calculates the average, highest and lowest marks.

## Test Case 2: Highest Marks
Enter students with different marks.
Expected: The student with the highest marks is displayed.

## Test Case 3: Tied Highest Marks
Enter two or more students with the same highest marks.
Expected: All students with the highest marks are displayed.

## Test Case 4: Lowest Marks
Enter students with different marks.
Expected: The lowest marks are displayed correctly.

## Test Case 5: Invalid Marks
Enter a mark greater than 100.
Expected: The program should reject the invalid mark, if validation is implemented.

## Edge Case 1: Minimum Marks
Enter 0 as a student's mark.
Expected: The program should accept 0.

## Edge Case 2: Maximum Marks
Enter 100 as a student's mark.
Expected: The program should accept 100.
