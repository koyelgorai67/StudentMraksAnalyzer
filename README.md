# Student Marks Analyzer

## About the Project
This is a beginner-friendly Java project that analyzes students' marks.

## Features
- Accepts student names and marks.
- Validates marks between 0 and 100.
- Calculates average marks.
- Finds the highest and lowest marks.
- Displays all students who scored the highest marks.

## Technologies Used
- Java
- VS Code

## Project Structure
StudentMarksAnalyzer/
├── src/
│   └── StudentMarksAnalyzer.java
└── README.md

## How to Run
1. Open the terminal.
2. Navigate to the src folder.
3. Compile the program:
   javac StudentMarksAnalyzer.java
4. Run the program:
   java StudentMarksAnalyzer
